# Native T3 Code iOS app and streaming chat references

Checked **2026-11-10**. This is a source study. I did not run or benchmark the apps. Links pin the exact commits read; a file's line number refers to that commit.

## Part A — Yes: the native app exists

**Yes. T3 Code has a separate native SwiftUI iPhone/iPad client in the same repository, on branch `t3code/rebuild-mobile-app-swift`, under `apps/swift-ios`.** It is separate from `apps/mobile`, rather than a second official repository. The branch README states: “A native SwiftUI client for T3 Code.” It targets iOS 17+, has its own Xcode project and bundle IDs, and installs beside the React Native app. Release identity: `com.t3tools.t3code.swiftui`; Debug: `com.t3tools.t3code.swiftui.dev`. See [README.md:1](https://github.com/pingdotgg/t3code/blob/f021c92cc97ceadef2a4d311df336aee77f31e3d/apps/swift-ios/README.md#L1) and [README.md:93](https://github.com/pingdotgg/t3code/blob/f021c92cc97ceadef2a4d311df336aee77f31e3d/apps/swift-ios/README.md#L93).

[Commit](https://github.com/pingdotgg/t3code/commit/f021c92cc97ceadef2a4d311df336aee77f31e3d). ### Performance evidence and its limits

The canvas comment attributes **about 60%** of transcript scroll hitches to per-paragraph `UITextView` creation, TextKit 2 layout, and teardown. The native text-cell comment says hosted SwiftUI reconstruction/measurement caused much of the remaining scroll cost. These are author comments; no device, trace, workload, or before/after result accompanies them in those files. Treat them as profiling clues. Excerpts: “about 60%” and “skip SwiftUI”. [Features/Chat/MarkdownTextCanvas.swift:10](https://github.com/pingdotgg/t3code/blob/f021c92cc97ceadef2a4d311df336aee77f31e3d/apps/swift-ios/Features/Chat/MarkdownTextCanvas.swift#L10); [Features/Chat/TranscriptTextMessageCell.swift:4](https://github.com/pingdotgg/t3code/blob/f021c92cc97ceadef2a4d311df336aee77f31e3d/apps/swift-ios/Features/Chat/TranscriptTextMessageCell.swift#L4).

`TranscriptScrollBenchmark` is stronger evidence of a deliberate test method. `T3_SCROLL_BENCHMARK=1` scrolls up/down at **3,000 pt/s**, runs cold and warm passes, requests **60–120 Hz / preferred 120**, and reports hitches, worst frame, main-thread busy p95, and counts above **1/120 s** and **1/60 s**. Excerpts: `over8` and `preferred: 120`. Its comment warns that simulator cadence can hide work exceeding an 8.33 ms device frame. This does **not** establish a measured 120 Hz result; run it on a ProMotion device and inspect render/GPU work too. [Features/Chat/TranscriptScrollBenchmark.swift:17](https://github.com/pingdotgg/t3code/blob/f021c92cc97ceadef2a4d311df336aee77f31e3d/apps/swift-ios/Features/Chat/TranscriptScrollBenchmark.swift#L17); [Features/Chat/TranscriptScrollBenchmark.swift:65](https://github.com/pingdotgg/t3code/blob/f021c92cc97ceadef2a4d311df336aee77f31e3d/apps/swift-ios/Features/Chat/TranscriptScrollBenchmark.swift#L65); [Features/Chat/TranscriptScrollBenchmark.swift:136](https://github.com/pingdotgg/t3code/blob/f021c92cc97ceadef2a4d311df336aee77f31e3d/apps/swift-ios/Features/Chat/TranscriptScrollBenchmark.swift#L136).
