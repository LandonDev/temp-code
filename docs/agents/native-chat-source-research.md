# Native chat source research

[Native chat rendering research](docs/research/native-chat-rendering.md)
records the public T3 Code SwiftUI app on `t3code/rebuild-mobile-app-swift`
(`apps/swift-ios`), separate from main's Expo app. It pins source lines for
T3, Signal, Exyte Chat, Stream Chat UIKit, and Enchanted, and explains which
techniques could carry over to our SwiftUI List. It reports source findings,
not verified 120 Hz device results. No app behavior changed in that study.
